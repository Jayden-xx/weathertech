# AI 프로젝트 포트폴리오 PRD — 초안

- 문서 작성일: 2026-11-14
- 대상: Codex 등 AI 도구로 만든 프로젝트를 소개하는 포트폴리오 사이트
- 상태: MVP 범위 확정, 참고 이미지 첨부 후 화면 배치 확정
- 포트폴리오 사이트명 및 공개 URL: 미정

## 1. 사이트 목적

AI로 아이디어를 실제 서비스로 구현하는 능력을 보여준다. 사용자가 기획·검수를 맡고 Codex로 구현한 결과물을 소개하며, 교육 수강생이 공개 사이트를 직접 체험할 수 있도록 한다.

첫 공개에서는 ‘기후의 흐름 · 중기예보’ 프로젝트 1개를 소개한다. 포트폴리오의 핵심은 프로젝트 목록에서 구현 결과를 발견하고, 상세 소개에서 프로젝트와 제작 방식을 이해한 뒤, 체험 버튼으로 실제 서비스에 접근하는 것이다.

구체적인 색상, 타이포그래피, 간격은 `디자인.md`에서 정한다. 이 PRD는 필요한 콘텐츠, 화면 동작, 탐색 흐름과 완료 기준을 정의한다.

## 2. 대상 방문자와 핵심 사용 시나리오

### 대상 방문자

교육 수강생. AI를 활용한 서비스 구현 사례를 살펴보고, 완성된 결과물을 직접 체험하려는 방문자다.

### 핵심 사용 시나리오

1. 수강생이 포트폴리오 사이트를 연다.
2. 프로젝트 목록에서 ‘기후의 흐름 · 중기예보’ 카드의 프로젝트명과 한 줄 소개를 확인한다.
3. 카드를 눌러 상세 소개로 이동한다.
4. 서비스 소개, 제작자의 역할, Codex 활용 방식을 확인한다.
5. ‘사이트 체험’ 버튼을 눌러 공개된 해상예보 페이지로 이동한다.
6. 공개 사이트에서 예보와 파고·날씨 시각화를 직접 살펴본다.

### MVP 성공 판단

프로젝트 목록 → 상세 소개 → 공개 사이트 체험의 흐름을 막힘없이 완료할 수 있으면 MVP의 핵심 목적을 충족한다. 방문·클릭 통계 수집 여부와 정량 목표는 미정이다.

## 3. 프로젝트 콘텐츠와 공개 링크

첫 공개 프로젝트 수는 1개다. 아래 한 줄 소개는 기존 대화와 구현 내용을 바탕으로 정리한 초안 문구다.

| 항목 | 콘텐츠 |
| --- | --- |
| 프로젝트명 | 기후의 흐름 · 중기예보 |
| 한 줄 소개 | 기상청 중기예보를 지역별 그래프·표와 움직이는 파도·날씨 그림으로 살펴보는 웹서비스 |
| 대표 이미지 | 미정 — 추후 첨부 예정 |
| 내가 맡은 역할 | 기획·검수 |
| 사용한 AI 도구와 활용 방식 | Codex — 기획 요구사항을 바탕으로 서비스 기능과 화면을 구현하고, 검수 의견에 따라 수정 |
| 공개 URL | https://weather-note-kma.workspace-482617.chatgpt.site/sea |

### 상세 소개에 필요한 정보

- 프로젝트명과 한 줄 소개
- 서비스가 하는 일: 기상청 중기전망·육상·기온·해상예보 조회 및 그래프·표 제공, 파고와 날씨의 애니메이션 표현
- 대표 이미지: 추후 첨부 예정. 이미지가 없는 상태에서도 프로젝트 소개와 사이트 체험은 가능해야 한다.
- 역할: 사용자가 기획·검수를 맡고 Codex로 구현했다는 사실
- AI 활용 방식: 기능·화면 구현 및 검수 의견에 따른 수정
- ‘사이트 체험’ 버튼과 확인된 공개 URL

제작 기간, 구체적인 제작 과정·성과, 추가 도구, 제작자 소개·연락처는 미정이다. 정하지 않은 정보나 링크는 임의로 채우지 않는다.

## 4. MVP 범위와 후속 기능

우선순위는 P0(첫 공개 필수), P1(후속 검토), 미정으로 구분한다. ‘제안’은 아직 채택되지 않은 선택지다.

### MVP

| 기능 | 방문자 또는 운영자 목적 | 우선순위 | 완료 기준 |
| --- | --- | --- | --- |
| 프로젝트 목록 | 수강생이 공개된 프로젝트를 발견한다. | P0 | 목록에 ‘기후의 흐름 · 중기예보’ 카드 1개와 한 줄 소개가 표시된다. |
| 프로젝트 상세 소개 | 수강생이 서비스 내용, 제작자의 역할과 AI 활용 방식을 이해한다. | P0 | 카드를 누르면 해당 프로젝트의 상세 소개가 열리고, 프로젝트명·한 줄 소개·기획 및 검수 역할·Codex 활용 방식이 표시된다. |
| 공개 사이트 체험 링크 | 수강생이 구현된 서비스를 직접 체험한다. | P0 | 상세 소개의 ‘사이트 체험’ 버튼을 누르면 비로그인 상태에서 `https://weather-note-kma.workspace-482617.chatgpt.site/sea`가 열린다. |
| 목록으로 돌아가기 | 수강생이 상세 소개에서 프로젝트 목록으로 복귀한다. | P0 · 제안 | 상세 소개의 ‘목록으로’ 동작으로 프로젝트 목록에 돌아갈 수 있다. 구체적인 UI 형태는 미정이다. |
| 대표 이미지 미첨부 상태 처리 | 운영자가 이미지 첨부 전에도 첫 공개를 할 수 있다. | P0 | 대표 이미지가 없어도 깨진 이미지가 표시되지 않으며, 목록·상세 소개·체험 버튼을 이용할 수 있다. |

### 후속 기능

| 기능 | 방문자 또는 운영자 목적 | 우선순위 | 완료 기준 |
| --- | --- | --- | --- |
| 대표 이미지 반영 | 수강생이 서비스의 실제 모습을 확인한다. | 추후 자료 제공 후 반영 | 전달받은 이미지가 프로젝트 콘텐츠에 반영되고, 이미지 설명이 제공된다. 노출 영역은 참고 이미지 확인 후 확정한다. |
| 프로젝트 추가 | 운영자가 새로운 AI 구현 사례를 소개한다. | P1 · 제안 | 두 번째 프로젝트를 추가하면 목록과 해당 상세 소개가 표시되고, 각 프로젝트의 체험 버튼이 지정된 URL로 연결된다. |
| AI 제작 과정 소개 확장 | 수강생이 기획·구현·검수 과정을 학습한다. | P1 · 제안 | 운영자가 제공한 제작 과정과 검수·수정 사례가 상세 소개에 표시된다. 자료와 구성은 미정이다. |

제안한 후속 기능의 채택 여부는 미정이다. 검색·필터, 관리자 편집 화면, 회원가입·로그인, 문의 기능 및 통계 기능은 현재 MVP에 포함하지 않으며, 후속 도입 여부도 미정이다.

## 5. 화면 구성과 탐색 흐름

### 화면 배치 원칙

**참고 이미지 첨부 후 확정.** 현재 참고 이미지가 없으므로 아래 내용은 필요한 정보와 동작을 정의한다. 실제 화면 영역의 위치, 순서, 크기와 정보 배치는 이미지 확인 후 결정한다. 상세 소개를 별도 페이지로 구성할지 등 표시 방식과 내부 URL 경로는 미정이다.

### 확인된 화면 요구사항

| 화면 또는 정보 영역 | 필요한 콘텐츠 | 필요한 동작 및 확정 상태 |
| --- | --- | --- |
| 프로젝트 목록 | 날씨 프로젝트 카드 1개, 프로젝트명, 한 줄 소개, 대표 이미지 상태 | 카드를 누르면 프로젝트 상세 소개로 이동한다. 목록의 구체적인 배치는 참고 이미지 첨부 후 확정한다. |
| 프로젝트 상세 소개 | 프로젝트명, 한 줄 소개, 서비스 설명, 대표 이미지 상태, 내가 맡은 역할, Codex 활용 방식 | 카드에서 진입할 수 있어야 한다. 상세 소개의 표시 방식은 미정이다. |
| 사이트 체험 진입점 | ‘사이트 체험’ 문구와 날씨 프로젝트 공개 URL | 버튼을 누르면 확인된 공개 사이트로 이동한다. 같은 탭 또는 새 탭으로 열지는 미정이다. |
| 목록 복귀 진입점 | ‘목록으로’ 문구 — 제안 | 상세 소개에서 목록으로 복귀한다. 채택 여부와 UI 형태는 미정이다. |
| 포트폴리오 목적 안내 | AI로 아이디어를 실제 서비스로 구현한 사례라는 설명 — 제안 | 안내 영역의 채택 여부, 문구와 위치는 참고 이미지 확인 후 결정한다. |

### 확정된 탐색 흐름

```text
프로젝트 목록
  → 날씨 프로젝트 카드 선택
  → 프로젝트 상세 소개
  → ‘사이트 체험’ 버튼 선택
  → 기후의 흐름 · 중기예보 공개 사이트의 /sea 화면
```

프로젝트 카드는 상세 소개로 연결하고, 체험 버튼은 공개 사이트로 연결한다. 카드 전체를 공개 사이트로 바로 연결하지 않는다.

### 추가 확인 사항

- 참고 이미지와 프로젝트 대표 이미지
- 포트폴리오 사이트명 및 공개 URL
- 상세 소개의 표시 방식과 내부 URL 경로
- 체험 링크를 같은 탭 또는 새 탭으로 여는 방식
- 제안한 복귀 동작 및 후속 기능의 채택 여부

참고 이미지가 첨부되면 이미지에 보이는 영역과 정보 배치를 검토해 이 절을 갱신한다. 시각 스타일의 세부 규칙은 `디자인.md`에서 별도로 정의한다.
