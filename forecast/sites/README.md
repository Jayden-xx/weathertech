# 기후의 흐름 Sites 배포본

기상청 MidFcstInfoService의 네 기능을 Sites의 Cloudflare Worker와 D1 공용 DB에서 실행합니다. 기존 로컬 프로젝트의 UI와 지역 코드 목록을 유지했습니다. 로컬 Python 서버나 사용자의 PC가 켜져 있을 필요가 없습니다.

## 구조

- `assets.mjs`: HTML, CSS, 브라우저 JavaScript, 가이드/Excel에서 확인한 지역, 명확히 표시한 모의 응답. 인증키 없음.
- `core.mjs`: KST 발표본·날짜 변환, JSON/XML 오류, 결측/0 구분, API 요청과 전역 호출 관리.
- `worker.mjs`: 네 페이지와 서버 API. 외부 호출은 서버에서만 수행.
- `drizzle/0000_gateway.sql`: 공용 D1의 캐시·호출 기록·재시도·전역 호출 예약 스키마.
- `build.mjs`: 독립 Worker 한 파일과 Sites manifest 생성. 외부 패키지 설치 불필요.
- `test.mjs`: 실제 SQLite로 검사하는 D1 어댑터와 모의 API 검증. `node --test test.mjs` 16개 통과.

## 인증과 공개 범위

Sites 프로젝트의 서버 비밀 환경변수 `KMA_SERVICE_KEY`를 사용합니다. KEY.env는 로컬 Python 버전 전용이며 Sites 소스나 배포 아카이브에 복사하지 않습니다. 인증키 변경은 Sites 비밀 설정 갱신 후 저장 버전을 배포해야 적용됩니다. 공개 방문자는 인증키를 입력하지 않습니다.

공개 범위는 사용자의 요청에 따라 public으로 설정했습니다. URL을 가진 사람이 접근할 수 있습니다. 인증키와 원본 환경 파일은 공개하지 않습니다.

## 캐시와 호출량

각 방문자가 기상청을 직접 호출하지 않습니다. 같은 기능·지역·발표시각·페이지·형식은 D1 성공 캐시를 공유합니다. 같은 Worker 안의 동일 요청은 Promise로 합치고, 다른 인스턴스 사이에는 D1 트랜잭션으로 전역 호출을 예약합니다. 전체 외부 요청의 시작 간격은 최소 30초이고, 진행 중 다른 외부 요청은 대기 안내를 반환합니다. 45초 예약 잠금은 강제 종료 시 복구용이며 외부 fetch 제한은 15초입니다.

최근 24시간 기록에 대해 8,000회 경고, 9,000회 상한을 적용합니다. 제공기관 호출 제한은 24시간 차단합니다. 호출·실패 기록과 캐시는 재배포 후에도 D1에 남습니다. 공식 자정 초기화 정책을 확인하지 못했으므로 rolling 24h로 보수적으로 계산합니다. 캐시가 있는 경우 한도 도달에도 이전 자료를 제공하며 마지막 API 성공시각을 표시합니다.

같은 키를 로컬 서버나 다른 앱에서도 사용하면 Sites DB 집계와 제공기관 집계가 다릅니다. Sites로 운영을 전환한 뒤 로컬 서버는 필요할 때만 사용하세요. 이 DB는 해당 Sites 프로젝트의 여러 인스턴스가 공유합니다. 서로 다른 Sites 프로젝트의 DB까지 자동 공유하지는 않습니다.

## 검증 범위

로컬 Node 24와 SQLite로 날짜·06시/18시·누락값·0·키 인코딩·JSON/XML 오류·캐시·동시 요청·전체 간격·호출 상한·제공기관 차단·이전 자료·응답 코드·비공개 파일 차단의 16개 검사를 통과했습니다. 실제 기상청 데이터를 가장한 고정 응답을 기본으로 제공하지 않으며 모의 응답은 사용자가 켠 체험 모드에만 표시합니다. 배포 환경의 실제 API 검증 결과는 작업 채팅에서 구분해 보고합니다.

기온 Low/High 계산 의미는 확정하지 않아 원문에만 남깁니다. 최근 24시간의 06/18시 후보를 사용하며 실제 게시 지연시간을 임의로 설정하지 않습니다. 키와 외부 요청 URL·오류 원문은 로그에 출력하지 않습니다.
