# 날씨 보스 — API 키 보관 및 연결 상태

## 현재 상태

- 공개 사이트: https://weather-boss-play-261114.workspace-482617.chatgpt.site
- KMA_SERVICE_KEY는 Sites 호스팅 서버의 비밀 환경변수로 등록했습니다.
- 공개 서버의 서울·대구·한라산 실제 예보 응답을 확인했습니다.
- 확인 후 공용 PC의 프로젝트 `.dev.vars`에서 키 값을 제거했습니다. 프로젝트 내부에서 같은 키 원문이 남은 파일은 발견되지 않았습니다.
- 로컬 개발 서버도 종료했습니다. 로컬 파일을 지웠거나 PC가 꺼져도 공개 사이트는 서버 비밀값으로 작동합니다.

## 사용하는 API

[기상청_단기예보 조회서비스](https://www.data.go.kr/data/15084084/openapi.do)

- getVilageFcst: TMP(기온), WSD(풍속), PTY(강수형태). 날짜별 연속 6시간을 선택합니다.
- getUltraSrtFcst: LGT(낙뢰). 단기예보와 동일 예보 시각일 때만 결합합니다.
- 낙뢰 자료가 없는 시간은 ‘자료 없음’이며 0으로 대체하지 않습니다.
- API 낙뢰 값은 실제 확률(%)이 아닙니다. 값이 0보다 크면 게임의 번개 공격을 활성화합니다.

## 지역과 날짜

서울 중구(60,127), 대구 중구(89,90), 제주 한라산 인근(53,35) 격자를 사용합니다. 한라산은 정상의 실측 기온이나 등산 안전 정보와 구분합니다.

날짜 메뉴에는 실제 단기예보가 제공되는 날짜만 표시합니다. 고정된 7일 목록은 표시하지 않습니다. 2026-11-14 확인 시 11월 14~17일을 선택할 수 있었습니다. 이후 제공 범위는 기상청 갱신에 따라 바뀝니다.

## 앞으로 키를 바꿀 때

개인 기기에서 포털 키를 관리하고, 교체 키를 Sites의 KMA_SERVICE_KEY 비밀 환경변수에 등록한 뒤 재배포하세요. 키는 채팅·브라우저 코드·소스 저장소·스크린샷에 넣지 마세요.

공용 PC에서의 원문 제거는 파일에 남아 있던 값을 제거한 것이며, 디스크 복구나 다른 프로그램의 이전 복사본까지 없애는 보안 삭제를 의미하지 않습니다. 이전 노출이 걱정되면 개인 기기에서 키를 재발급하고 서버 비밀값을 교체하는 편이 확실합니다. 이번 작업에서는 키 재발급은 수행하지 않았습니다.

로컬에서 실제 API 개발을 다시 하려면 개인 기기의 `.dev.vars`에 키를 설정할 수 있습니다. 현재 공용 PC의 파일에는 빈 값만 남아 있습니다.
