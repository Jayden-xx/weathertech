- 날짜 선택은 KST 기준 오늘부터 7일을 표시한다. 실제 단기예보에서 연속 6시간을 확보한 날짜만 활성화한다. 검증 시점에는 11/14~11/17 제공, 11/18~11/20 미제공이다. 이후 갱신에 따라 달라진다.
- 단기예보 getVilageFcst의 TMP/WSD/PTY와 초단기예보 getUltraSrtFcst의 LGT를 동일 유효 시각으로 결합한다. 미래의 초단기 범위 밖 LGT는 null로 유지하고 ‘자료 없음’으로 표시한다. 이를 0이나 번개 없음으로 대체하지 않는다.
- LGT는 확률(%)이 아니다. 유효한 낙뢰 신호가 0보다 조금이라도 크면 해당 시간 구간에서 번개를 1회 생성한다. 경고선 0.75초 후 낙뢰, 적중 시 하트 1 감소. 무적 시간은 기존 충돌과 공유한다.
- UI는 지역·날짜 선택 상자를 제공하며, 플레이/일시정지 중 선택을 잠근다. 선택 변경 시 기존 상태를 초기화하고 새 데이터 로딩 상태를 표시한다. 이전 요청의 응답이 새 선택에 덮어쓰이지 않도록 한다.
- 실제 예보에 낙뢰가 없을 때도 확인할 수 있도록 ‘번개 패턴 체험 · 예시’를 제공한다. 이 경우 예시 표시를 유지하고 실제 예보로 오인하게 하지 않는다.
- 사용자 승인에 따라 KMA_SERVICE_KEY를 호스팅 서버의 비밀 환경변수에 등록했다. 공개 서버 연결 검증 후 공용 PC의 .dev.vars에서 키를 제거한다. 키는 공개 소스·브라우저 번들에 포함하지 않는다.
- 검증: 게임·낙뢰·날짜·결측 처리 13개 테스트와 타입 검사 및 빌드 통과. 로컬 세 지역 실제 예보와 날짜 선택 확인. 공개 배포 연결 결과는 별도 완료 기록에 남긴다.

## 버전 3 — 날짜·지역 배경·극한 예시

- 날짜 선택은 API 응답의 availableDates만 표시한다. 7일 고정 목록과 ‘예보 미제공’ 항목은 제거한다. 로딩·연결 실패 시에는 비활성 안내만 표시한다.
- 대구 배경은 산 능선·도심·전망 타워에서 영감을 받은 독자적인 픽셀 일러스트다. 실제 위치를 재현한 지도는 아니다.
- 데이터 선택 메뉴: 실제 단기예보 / 극한 폭염 / 낙뢰 폭주 / 초강풍 태풍. 마지막 세 항목은 창작 예시임을 화면과 결과에 표시한다.
- 예시 덤프는 public/data/weather-scenarios.json에 포함하고 다운로드 링크도 제공한다. 실제 관측·예보·과거 재난 기록으로 표시하지 않는다. 예시 모드에는 날짜 선택을 표시하지 않는다.
- 폭염은 39~46°C, 태풍은 35~60m/s의 가상 값으로 구성한다. 폭염·강풍에서는 장애물 생성 간격과 속도가 증가한다. 높은 낙뢰 값은 반복 경고와 번개를 생성한다. 모든 수치-공격 연결은 게임적 해석이다.
- 공개 서버의 API 비밀값과 접근 권한을 유지하며 공용 PC에 키를 다시 저장하지 않는다.
- 검증: 기존 13개와 극한 프로필·강풍 궤적·폭염 생성빈도·반복 낙뢰 4개를 합쳐 17개 테스트 통과.
