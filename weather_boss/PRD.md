# PRD — 날씨 보스

문서 상태: MVP 구현을 위한 초안
작성일: 2026-11-14

- **확정**: 사용자 답변과 ‘제안대로 진행’에서 채택된 요구사항.
- **제안**: 구현을 구체화하기 위해 추가한 기본값·처리 방식.
- **미정**: 아직 제공되지 않은 사실·콘텐츠·운영 정보.
- 이 문서는 화면에 필요한 정보와 동작을 정의한다. 구체적인 색상, 타이포그래피, 간격, 모서리, 애니메이션 수치는 `디자인.md`에서 정한다.

## 1. 사이트 목적

### 목적과 전달 내용

**확정**: 11주간의 기후테크 학습을 바탕으로 공공데이터를 인터랙티브한 웹게임으로 활용하는 역량을 보여준다. 강사·동료에게 시연하고, 이후 개인 이력에 활용할 수 있는 포트폴리오 결과물을 만든다.

**확정**: 프로젝트명은 **날씨 보스**다. 단일 프로젝트의 소개와 실제 게임을 같은 페이지에서 제공한다. 방문자는 회원가입이나 로그인 없이 바로 게임을 시작할 수 있다. 자동 플레이 대신 방문자가 시작 버튼을 눌러 시작한다.

### 핵심 경험

**확정**: 서울의 시간별 기상청 예보를 짧은 플레이에 압축한 좌우 회피 게임이다. 게임 길이는 12초, 시작 체력은 하트 3개다. 방문자는 장애물을 피하고 끝까지 생존하는 것을 목표로 한다.

**제안**: 소개 문구는 ‘오늘의 예보가 공격 패턴이 된다. 12초 동안 날씨 보스를 버텨라.’로 한다. 이 문구는 편집 가능한 콘텐츠 초안이다.

### 전달의 정확성

- 기상 예보를 창작한 게임 규칙으로 변환한 체험임을 알린다.
- 게임 중 매초 실제 날씨가 바뀐다는 의미의 ‘실시간 변화’를 주장하지 않는다.
- 하루의 예보만으로 장기 기후변화 추세를 입증하지 않는다.
- 체력·장애물·난도는 게임 지표이며 건강 위험, 재해 위험 또는 실제 안전 등급이 아니다.

## 2. 대상 방문자와 핵심 사용 시나리오

### 대상 방문자

| 대상 | 방문 목적 | 기대 행동 |
|---|---|---|
| 강사·동료 수강생 | 수업에서 배운 내용을 어떻게 활용했는지 확인 | 한 판 플레이 후 데이터 반영 방식 확인 |
| 향후 포트폴리오 평가자 | 문제 정의·데이터 활용·구현 결과와 기여 확인 | 게임 체험 후 제작 소개 읽기 |
| 공개 링크로 유입된 일반 방문자 | 짧고 이해하기 쉬운 게임 체험 | 비로그인 플레이, 재도전 |

### 핵심 시나리오

1. 외부 공개 URL에 로그인하지 않은 상태로 접속한다.
2. 첫 화면에서 제목, 한 줄 설명, 12초 생존 목표, 조작법을 확인한다.
3. 데이터가 준비되면 ‘게임 시작’을 누른다. 별도 상세 페이지나 외부 서비스로 이동하지 않는다.
4. 키보드 좌우 키 또는 모바일 터치 버튼으로 캐릭터를 움직이며 장애물을 피한다.
5. 성공 또는 실패 결과와 생존 시간을 확인한다.
6. ‘다시 도전’으로 재시작하거나 ‘데이터·제작 과정 보기’로 같은 페이지 아래 설명을 읽는다.

### 예외 시나리오

- **확정**: API 연결에 실패하면 명시된 예시 데이터로 체험할 수 있다.
- **제안**: API 오류 시 ‘실제 예보를 불러오지 못했습니다’와 재시도·예시로 체험하기를 표시한다. 예시 선택은 방문자가 수행하며 자동으로 실제 자료인 것처럼 대체하지 않는다.
- **제안**: 화면 전환·탭 이탈 시 일시정지하고 복귀 후 재개 버튼으로 이어서 플레이한다.
- **제안**: 역할·공개 URL 등 미제공 정보는 해당 상태를 분명히 표시하며 임의 사실로 채우지 않는다.

## 3. 프로젝트 콘텐츠와 공개 링크

### 첫 공개 콘텐츠

| 항목 | 내용 |
|---|---|
| 프로젝트명 | **날씨 보스** — 확정 |
| 한 줄 소개 | **제안**: 서울의 시간별 예보를 12초의 장애물 회피 게임으로 바꾸는 인터랙티브 웹 프로젝트 |
| 대표 이미지 | **확정**: 완성된 게임 화면 캡처 사용. 실제 이미지 파일은 미정 |
| 내가 맡은 역할 | **미정** — 정보통신공학 배경·디자인 관심은 확인됐으나 실제 프로젝트 기여와 동일시하지 않음 |
| 사용한 AI 도구와 활용 방식 | **미정** — Codex·Gemini 등을 배운 사실과 이 프로젝트의 실제 사용 이력을 구분 |
| 공개 URL | **미정** — 구현·배포 후 실제 외부 접속 URL을 새로 발급하고 기록 |

### 공개·링크 요구사항

- **확정**: 링크를 아는 누구나 계정·로그인·초대 없이 접속해 플레이할 수 있는 공개 웹사이트로 배포한다.
- 공개 URL 발급은 구현·배포 단계의 완료 조건이다. PRD 작성만으로 발급되었다고 표시하지 않는다.
- **제안**: 도메인은 배포 서비스가 발급한 HTTPS 주소를 우선 사용한다. 별도 도메인 구매는 후속 검토다.
- 단일 페이지가 소개와 공개 게임을 함께 제공하므로 프로젝트 소개의 기본 CTA는 ‘이 페이지에서 플레이’다.
- 공개 URL이 현재 페이지와 같으면 ‘사이트 열기’ 버튼을 중복 배치하지 않는다. URL 확정 후 공유용 링크를 제공한다.
- 다른 주소가 제공될 경우에만 ‘사이트 열기’를 해당 공개 URL로 연결하고 새 탭 열림을 안내한다.
- URL 미정 상태에서는 가짜 주소나 동작하지 않는 링크를 제공하지 않고 ‘공개 URL 미정’을 표시한다.

## 4. MVP 범위와 후속 기능

우선순위: **P0**는 첫 공개 필수, **P1**은 첫 공개 후 개선, **P2**는 확장 검토다.

| 기능 | 방문자 또는 운영자 목적 | 우선순위 | 완료 기준 |

| 비로그인 공개 접속 | 링크만으로 체험 | P0 | 새 브라우저의 비로그인 상태에서 공개 HTTPS URL이 열리고 가입·인증 없이 시작 가능 |

| 예시 모드·오류 복구 | API 장애 중에도 체험 | P0 | 키 미설정·네트워크 오류·필수값 누락 시 오류 안내와 예시 체험·재시도 버튼이 나타나며 예시 선택 후 게임 가능 |

| 승리·패배·재시작 | 한 판 완결 | P0 | 12초 생존 시 성공, 하트 0이면 실패. 결과에 생존 시간·모드·기간을 표시. 재시작 시 체력·장애물·타이머가 초기화 |
| 일시정지·재개 | 이탈·중단 대응 | P0 | 버튼 또는 Esc로 정지, 탭 이탈 시 자동 정지. 재개 전까지 장애물·남은 시간·무적 시간이 진행되지 않음 |
| 데이터·제작 소개 | 학습 결과 설명 | P0 | 출처·변환 규칙·역할·AI 활용 항목이 있으며 미확정 항목은 ‘미정’으로 표시 |
| 대표 이미지 자리 | 결과물 소개 | P0 | 실제 캡처가 없으면 ‘게임 화면 준비 중’ 표시. 공개 시 실제 게임 캡처로 교체 |
| 기본 접근성·반응형 | 다양한 입력으로 이용 | P0 | 모바일에서 가로 스크롤 없이 주요 정보·조작에 접근. 키보드로 시작·정지·재시작 가능. 호버 없이 소개·링크 접근 가능 |
| 인증키 보호 | 공개 배포 시 키 관리 | P0 | API 키가 공개 소스·브라우저 응답에 포함되지 않고 서버측 설정을 사용. 브라우저에 키를 입력하라고 요구하지 않음 |

실제 API 연결과 예시 모드가 모두 요구사항이다. 예시로 플레이할 수 있어도 API 미연결이면 공공데이터 연동 기능은 미완료로 기록한다.

### 탐색과 카드 동작

- 프로젝트는 하나이며 프로젝트 목록·별도 상세 페이지를 만들지 않는다.
- 프로젝트 요약 카드 본문은 클릭 영역으로 만들지 않는다. 역할·AI 활용·한 줄 소개는 펼침이나 호버 없이 읽을 수 있다.
- ‘이 페이지에서 플레이’는 준비 영역으로 이동한다. 설명 영역에서 복귀할 때 임의로 게임을 시작하거나 결과를 초기화하지 않는다.

- **제안**: 데스크톱은 게임 옆에 예보 요약을 둘 수 있다. 모바일은 게임 아래에 터치 조작과 예보 요약을 순서대로 배치한다.

## 업데이트 명세 — 2026-11-14, 버전 2

이 절이 기존의 상충하는 범위·진행 시간·API 상태 설명보다 우선한다.

- 게임 시간은 **12초**다. 지역과 날짜에 맞는 연속 6시간 예보를 압축한다.
- 지역 선택은 **서울 중구 / 대구 중구 / 제주 한라산**을 제공한다. 격자는 각각 (60,127), (89,90), (53,35)다. 한라산은 기상청 백록담 관측소 좌표를 변환한 인근 예보 격자이며 정상 실측과 구분한다.

- 단기예보 getVilageFcst의 TMP/WSD/PTY와 초단기예보 getUltraSrtFcst의 LGT를 동일 유효 시각으로 결합한다. 미래의 초단기 범위 밖 LGT는 null로 유지하고 ‘자료 없음’으로 표시한다. 이를 0이나 번개 없음으로 대체하지 않는다.
- LGT는 확률(%)이 아니다. 유효한 낙뢰 신호가 0보다 조금이라도 크면 해당 시간 구간에서 번개를 1회 생성한다. 경고선 0.75초 후 낙뢰, 적중 시 하트 1 감소. 무적 시간은 기존 충돌과 공유한다.
- UI는 지역·날짜 선택 상자를 제공하며, 플레이/일시정지 중 선택을 잠근다. 선택 변경 시 기존 상태를 초기화하고 새 데이터 로딩 상태를 표시한다. 이전 요청의 응답이 새 선택에 덮어쓰이지 않도록 한다.
- 실제 예보에 낙뢰가 없을 때도 확인할 수 있도록 ‘번개 패턴 체험 · 예시’를 제공한다. 이 경우 예시 표시를 유지하고 실제 예보로 오인하게 하지 않는다.
